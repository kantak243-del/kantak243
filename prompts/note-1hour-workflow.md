# 4,000字の有料noteを1時間で仕上げるプロンプト集

X（@rimuruafi）のスレッドで紹介されていた手順を整理したもの。
①②④は投稿の内容をもとにしている。③は画面に映っていなかったため、前後の流れから補った（**[補完]** と表記）。

`[ ]` の部分は自分の内容に置き換えて使う。

---

## 全体の流れ

| ステップ | 時間 | やること |
| --- | --- | --- |
| ① | 0〜10分 | 売れるテーマを10個出させる |
| ② | 10〜15分 | 10個を採点して1つに絞る |
| ③ | 15〜50分 | 構成を作って本文を書く **[補完]** |
| ④ | 50〜60分 | タイトルと有料ラインを決める |

---

## ① 【0〜10分】売れるテーマを10個出させる

Claudeに、これをそのまま送る。

```
noteで500円の有料記事を初めて出します。私の経験は【〇〇】です。
この経験を活かして、1年後も同じ悩みで検索されそうなテーマを10個出してください。
それぞれ、読む人、その人が困っていること、記事を読んだ後にできる[ようになることを1行ずつ添えてください。]
```

※ 元の投稿は「記事を読んだ後にできる」の先が「さらに表示」で切れているため、`[ようになること]` 以降は推測。
→ 【〇〇】には、職業・年数・得意分野など自分の経験を具体的に入れる。

---

## ② 【10〜15分】10個を採点して1つに絞る

```
さっきの10個を、500円払ってでも読みたい度合い、1年後も読まれるか、
私の経験が活きるか、の3項目で10点満点で採点して。
合計点が高い順に並べて、1位を選んだ理由も書いて。
```

→ 迷ったら、自分が一番詳しく語れるものを選ぶ。

---

## ③ 【15〜50分】構成を作って本文を書く **[補完]**

### 構成（15〜20分）

```
選んだテーマ「[テーマ]」で、4,000字のnoteの構成を作って。
以下の順番で、見出しごとの要点と目安の文字数を出して。
1. 読者の悩みへの共感（導入）
2. よくある間違い・うまくいかない理由
3. 私の経験・失敗談
4. 解決策（具体的な手順）
5. 実践例・テンプレート
6. まとめと次の一歩
```

### 本文（20〜50分）

```
この構成で本文を書いて。条件：
- 一文は短く、専門用語には一言で説明を添える
- 「私の経験」の部分は、以下のエピソードを使う：[自分の体験を箇条書き]
- 抽象論で終わらせず、読者がそのまま真似できる手順・例を入れる
```

→ AIの下書きに自分の具体的な体験・数字を書き足すのがこのステップの本番。ここを省くと誰でも書ける記事になる。

---

## ④ 【50〜60分】タイトルと有料ラインを決めさせる

```
このnoteのタイトルを5案出して。
あと、読者が一番続きを読みたくなる一文の直後で、無料部分と有料部分を分けて。
```

→ 有料ラインは「答えの直前」。ここがズレると、1部も売れない。
