# ファネルテンプレート(④⑤⑥)

バズ投稿からリストを獲得し、教育→販売につなげるための文面テンプレート集。
配信・運用そのものはこのスキルの範囲外(メルマガ配信ツール、LINE公式アカウント等はユーザー側で操作)。
Claudeは文面のドラフト作成までを担当する。

## ④ リスト獲得導線(プロフィール/固定ポスト)

- プロフィール欄: 「【提供価値を一言】→詳しくはプロフィールのリンクから」
- 固定ポスト構成: フック(バズ投稿と同じ型)→価値提示→無料プレゼントの案内→リンク誘導
- バズ投稿の返信欄: 「もっと詳しく知りたい人はプロフィールへ」の定型リプライ

チェックリスト:
- [ ] 無料プレゼント(リードマグネット)は明確か?ターゲットの悩みに直結しているか?
- [ ] リンク先の登録フォームは1ステップで完結するか?
- [ ] バズった投稿には全て同じ導線リプライを付けているか?

## ⑤ 教育コンテンツ配信(ステップ配信 5〜7通)

一般的な構成(PASONAの法則ベース):

1. **信頼構築**: 自己紹介+なぜこの情報を発信しているか
2. **問題提起**: ターゲットが気づいていない/放置している問題
3. **問題の深掘り**: 放置するとどうなるか(煽りすぎない範囲で)
4. **解決の方向性**: 問題の解決策の全体像(ノウハウの一部を無料開示)
5. **社会的証明**: 実績・事例・お客様の声(捏造しない、事実ベース)
6. **限定性・提案予告**: 次回、具体的な解決策(商品)を案内する旨を伝える
7. **オファー導線**: セールスレターへ誘導

各通、件名・本文・次回予告の3点セットでドラフトする。誇大表現・断定的な効果保証は避ける。

## ⑥ セールスレター(QUEST/PASONA構成)

構成例(QUESTフォーマット):

- **Qualify(絞り込み)**: 「こんな人におすすめ」で対象者を明確化
- **Understand(理解)**: 読者の悩み・現状への深い共感
- **Educate(教育)**: なぜこの商品が解決策になるのか、根拠を示す
- **Stimulate(刺激)**: 得られる未来・ベネフィットを具体的に描く
- **Transition(行動)**: 特典・保証・価格提示、明確なCTA

セールスレター作成時の注意:
- 「絶対」「必ず」「誰でも簡単に」等の断定的表現は景品表示法・薬機法リスクがあるため使わない
- 実績・お客様の声は事実に基づくもののみ使用する
- 返金保証・特定商取引法表記など法的に必要な記載を忘れずに案内する(内容自体の作成はユーザー確認のうえで)
