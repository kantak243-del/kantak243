# バズ投稿の収集ガイド(①)

現時点のセッションはX API / Grok APIに接続されていないため、収集は以下のいずれかの方法で人手を介して行う。

## 方法A: Grok(またはX標準検索)に直接聞く
Grok / X の検索UIに以下のようなプロンプトを投げ、結果を手作業でコピーする。

```
直近30日で「(あなたのジャンル、例: 副業 / マーケティング / エンジニア転職)」
カテゴリでインプレッション・保存数が多かった日本語ポストを50件、
本文全文・いいね数・リポスト数・URLの形式でリストアップして
```

ジャンルを2〜3種類に分けて聞くと偏りが減る(例: 「悩み共感系」「ノウハウ系」「暴露系」など)。

## 方法B: 自分で巡回してリストアップ
気になるアカウント・ハッシュタグ・トレンドタブを巡回し、明らかに伸びている投稿(目安: いいね1000+、または自分のフォロワー規模の10倍以上のインプレッション)を手動でメモする。

## 収集したら `data/buzz-posts/collected-posts.csv` に貼り付ける

列の意味:

| 列名 | 内容 |
|---|---|
| id | 連番 |
| url | 投稿URL(あれば) |
| author | アカウント名(任意、匿名化してもよい) |
| genre | ジャンル(副業/転職/健康/恋愛 など) |
| text | 投稿本文全文 |
| likes | いいね数 |
| reposts | リポスト数 |
| impressions | インプレッション数(不明なら空欄) |
| posted_at | 投稿日(不明なら空欄) |
| notes | 気づいたこと(任意) |

- 最低20〜30件、理想は100件集める。
- CSVなので本文中にカンマ・改行・ダブルクォートが入る場合は `"..."` で囲む。
- 埋め終わったら「分析して」とClaude Codeに依頼すれば、SKILL.md のフェーズ2が実行される。
