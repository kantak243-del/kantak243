# ヒアリングチェックリスト(③ 量産フェーズ)

投稿案を生成する前に、以下をユーザーに確認する(すでに文脈でわかっている項目は聞き直さなくてよい)。

1. **テーマ・ジャンル**: 今回の投稿で扱う話題は?
2. **ターゲット**: 誰に向けた投稿か?(属性・悩みレベル)
3. **ゴール**: 認知拡大/保存数/プロフィール遷移(リスト導線)のどれを優先するか?
4. **トーン**: 誠実・煽り気味・フランク・権威的、どれに寄せるか?
5. **使いたい型**: `pattern-library.md` の型から指定があるか、おまかせか?
6. **NGワード・避けたい表現**: 誇大表現規制、競合批判の可否など
7. **CTA**: リプ誘導/フォロー/プロフィールのリンク誘導、どれを入れるか?
8. **本数**: 何案生成するか(デフォルト5案)

回答が揃ったら、`pattern-library.md` の型を1〜3種類使い分けて投稿案を生成する。
各案には「使用した型」「想定フック」「CTA」を明記する。
