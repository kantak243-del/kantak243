# X バズ投稿エンジン

Xでバズった投稿を収集→分析→型化→量産→リスト化→教育→販売、という一連のファネルを回すためのスキル。
全体の流れ(ユーザー原案の7ステップ)と、このスキルが担当する範囲は以下の通り。

| # | ステップ | このスキルでの担当 |
|---|---|---|
| ① | バズ投稿100個収集 | `references/collection-guide.md` の手順でユーザーが収集し、`data/buzz-posts/collected-posts.csv` に貼り付ける。Claude はAPIキー未設定の間は自動収集できないため、収集作業そのものはユーザー(またはユーザー経由のGrok)が行う前提 |
| ② | 型と伸びるネタを分析 | Claude が `collected-posts.csv` を読み、`data/buzz-posts/pattern-analysis.md` に分析結果を書き出す |
| ③ | スキル化して量産 | 分析結果から `references/pattern-library.md` を更新し、`references/hearing-checklist.md` でヒアリングしてから投稿案を複数生成する |
| ④ | 伸びた投稿からリスト取得 | 自動化不可(X上の実操作が必要)。`references/funnel-templates.md` にリード獲得導線のチェックリストを用意 |
| ⑤⑥ | 教育文・セールスレター配信 | 配信自体は不可だが、`references/funnel-templates.md` のテンプレートを使って文面をClaudeが作成する |
| ⑦ | 着金 | ビジネス上の結果。このスキルの範囲外 |

## 使い方(フェーズ別)

### フェーズ1: 収集
ユーザーに `references/collection-guide.md` を提示し、`data/buzz-posts/collected-posts.csv` に埋めてもらう。
最低20〜30件、理想は100件。件数が少ない場合は「型の抽出精度が落ちる」旨を伝えた上で続行してよい。

### フェーズ2: 分析
1. `data/buzz-posts/collected-posts.csv` を読み込む。
2. 各投稿を以下の軸でタグ付けする:
   - **フック型**: 逆張り/共感/数字提示/悩み言語化/ビフォーアフター/暴露・裏話/権威性/ストーリー/挑発 など
   - **構造**: 1行フック→結論→根拠→CTA、リスト形式、スレッド、対比構造 など
   - **感情ドライバー**: 怒り/焦り/羨望/安心/好奇心/共感 など
   - **推定バズ理由**: なぜ伸びたか(タイミング、独自性、可読性、保存性など)
3. `data/buzz-posts/pattern-analysis.md` に、投稿ごとのタグ付けと、上位パターンの集計(頻出フック型トップ5など)を書き出す。

### フェーズ3: スキル化(型ライブラリ更新)
分析結果から再利用可能な「型」を5〜10個に抽象化し、`references/pattern-library.md` に
「型の名前」「使う場面」「テンプレ構文(プレースホルダ入り)」「実例」の形で追記する。
既存の型と重複する場合はマージし、テンプレを陳腐化させない。

### フェーズ4: ヒアリング→量産
`references/hearing-checklist.md` の質問でユーザーからヒアリングし、
`pattern-library.md` の型を使って投稿案を複数(デフォルト5案)生成する。
各案に「使用した型」「想定フック」を明記し、ユーザーが選びやすくする。

### フェーズ5〜6: リスト化・教育・セールス
`references/funnel-templates.md` を使い、
- プロフィール/固定ポスト用のリード導線文
- 教育ステップ配信(5〜7通)の構成とドラフト
- セールスレター(PASONA/QUEST構成)のドラフト
をユーザーの商品・ターゲットに合わせて作成する。配信自体(メルマガツール操作など)はスキル範囲外なので、
文面作成までを担当し、配信は本人が行う旨を明確に伝える。

## 注意点
- 実在のGrok/X APIは接続されていない前提で書かれている。API連携ができる環境では、収集ステップをスクリプト化してよいが、その場合も出力フォーマットは `collected-posts.csv` に合わせる。
- 誇大表現・虚偽の実績・薬機法/景品表示法に抵触しかねない訴求(「絶対」「必ず稼げる」等)は生成しない。教育文・セールスレターも同様。
- 個人情報を含む投稿者情報を無断でリスト化・連絡先収集する用途には使わない。
