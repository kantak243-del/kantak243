## 焔尾竜討伐

灰霧の谷に居座る焔尾竜ヴァルグを狩る 3D アクション。three.js 製。

- 太刀で **3連斬り**、長押しで **溜め斬り**（3段階）
- **回避**中は無敵。スタミナを消費
- 竜の **頭は弱点**（オレンジの数字）。**尻尾は斬り落とせる**
- 竜は噛みつき・尻尾回転・突進・火球で攻撃。HP が減ると **怒り状態** になり速くなって火球が3連に
- 突進を **岩に誘導** するとよろける
- 3回力尽きるとクエスト失敗

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 / ダッシュ | WASD / Shift | 左側をなぞる（端まで倒すとダッシュ） |
| 3連斬り | クリック / J | 攻撃 |
| 溜め斬り | 右クリック長押し / K | 溜め（長押し→離す） |
| 回避 | Space | 回避 |
| 回復薬 | R | 回復 |
| 竜の方を向く | Q | 注目 |
| カメラ | マウス / 矢印キー | 右側をなぞる |
| 一時停止 | P | II ボタン |

## ほたる狩り

夏の夜の川辺で、網を動かしてほたるを集めるブラウザゲームです。

### 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要）。

- **ほたる**（黄緑）：1点。続けて取るとコンボ倍率が上がります（5匹ごとに ×2, ×3 … 最大 ×5）
- **金ぼたる**（橙）：10点。提灯（ライフ）が減っていれば1つ回復
- **蜂**：網に入ると提灯が1つ消えます。3つ消えるとゲームオーバー
- ほたるを取り逃がすとコンボが途切れます
- 時間が経つほど、ほたるも蜂も速く・多くなります

### 操作

| 操作 | スマホ | PC |
| --- | --- | --- |
| 網を動かす | 画面を指でなぞる | マウス / ← → / A D |
| 一時停止 | II ボタン | P / Esc |

自己ベストはブラウザに保存されます。
