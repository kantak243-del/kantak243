# kantak243

フリーランス案件獲得用のリンクインバイオ型ポートフォリオページ (`index.html`)。

## 公開方法 (GitHub Pages)

1. リポジトリの **Settings > Pages** を開く
2. **Source** を `Deploy from a branch` に設定
3. Branch を `main` / `(root)` にして **Save**
4. 数分後、`https://kantak243-del.github.io/kantak243/` で公開される

## カスタマイズ

`index.html` を編集して、実績・スキル・連絡先を最新の内容に更新してください。
