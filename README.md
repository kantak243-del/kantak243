## 焔尾竜討伐

灰霧の谷に居座る焔尾竜ヴァルグを狩る 3D アクション。three.js 製。

- **武器は5種類**（加工屋の「武器」タブで持ち替え。強化段階は全武器共通）

  | 武器 | 特徴 |
  | --- | --- |
  | 太刀 | バランス型。3連斬りと溜め斬り（3段階） |
  | 大剣 | 遅いが一撃が重い。溜め斬りが最大の火力。溜め中は正面の攻撃をガード |
  | 双剣 | 手数型。強攻撃で **剣舞**（スタミナを使い続けて攻撃が速く・強く）、剣舞中の強攻撃は回転斬り **乱舞** |
  | 弓 | 遠距離。速射と溜め撃ち（最大4本）。溜め中は歩ける。竜の方へ自動で狙う |
  | ハンマー | 頭を叩き続けると竜が **気絶**。溜めて離すと振り上げ |

  1秒あたりのダメージの目安（強化1段階・竜の胴体に当て続けた場合の実測）: 太刀 連撃52/溜め64、大剣 連撃48/溜め72、ハンマー 連撃51/溜め55（＋気絶）、双剣 通常46/剣舞60、弓 速射38/溜め撃ち50前後
- **回避**中は無敵。スタミナを消費
- 竜の **頭は弱点**（オレンジの数字）。**尻尾は斬り落とせる**
- 竜は噛みつき・尻尾回転・突進・火球で攻撃。HP が減ると **怒り状態** になり速くなって火球が3連に
- 突進を **岩に誘導** するとよろける
- 3回力尽きるとクエスト失敗。**失敗しても残念賞**として、竜の体力を削った割合に応じて素材1〜4個・報酬金の10〜40%・少しのHRポイントがもらえる（尻尾を切っていれば尻尾も）
- **★6 蒼雷竜ゼルガ**（タイトルでクエストを切り替え）：体力1.6倍・攻撃1.35倍・より速く大きい強敵
  - 地面に光る輪が出たあとに **落雷**（怒ると6か所）
  - 翼で **跳びかかり**、着地の衝撃波
  - **噛みつきの連続**（怒ると3連）
  - 嵐の夜の狩場。新素材で太刀を6・7段階目（攻撃力196・225）に強化できる
- **★8 獄炎竜アグニヴァ**：体力7200・攻撃1.6倍。火球3連（怒ると5連）、地面から噴く **火柱**、体が赤く光ったあとの **周囲大爆発**、跳びかかり、3連噛みつき
- **★10 天冥竜ゼノギア**：体力11000・攻撃2倍。雷も炎もすべての技を使う。体力が半分を切ると **覚醒**（ずっと怒り状態・さらに速く）し、12か所に **星が降る**
- ★8・★10の素材で太刀を11段階目（攻撃力360）まで強化できる
- **防具**（加工屋の「防具」タブ）：竜ごとの素材で作って装備。受けるダメージが減り、スキルが付く。見た目の色も変わる

  | 防具 | 防御 | スキル |
  | --- | --- | --- |
  | ハンター装備 | 0% | なし |
  | 焔尾装備 | 15% | 火耐性 |
  | 蒼雷装備 | 25% | 雷耐性・回避性能 |
  | 獄炎装備 | 35% | 体力+50・火耐性（大） |
  | 天冥装備 | 45% | 攻撃+10%・スタミナ消費-40%・体力+30・火雷耐性 |
- **ランダムスキル**：防具を作ると、上の固定スキルとは別にランダムなスキルが2〜4個付く（強い防具ほど数とレベルが高い）
  - 自動回復・攻撃・体力・防御・回避性能・スタミナ急速回復・火耐性・雷耐性・回復量UP・溜め短縮・咆哮無効
  - 加工屋の **スキル錬成**（お金を払う）で付け直せる。結果を見てから「新しいスキル」か「前のまま」かを選べる
- **セーブ**：自動保存。一時停止メニューの「中断」で途中から再開できる（20秒ごとにも自動で中断データを保存）
- 狩りで集めた素材とお金で **加工屋** から太刀を強化（全11段階、攻撃力 100→360）
- ハンターランク・討伐数・最速タイムを記録

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 / ダッシュ | WASD・矢印キー / Shift | 左側をなぞる（端まで倒すとダッシュ） |
| 3連斬り | クリック / J | 攻撃 |
| 溜め斬り | 右クリック長押し / K | 溜め（長押し→離す） |
| 回避 | Space | 回避 |
| 回復薬 | R | 回復 |
| 竜の方を向く | Q | 注目 |
| カメラ | マウス（前進中は自動で背後に回る） | 右側をなぞる |
| 一時停止 | P | II ボタン |

## ほたる狩り

夏の夜の川辺で、網を動かしてほたるを集めるブラウザゲームです。

### 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要）。

- **ほたる**（黄緑）：1点。続けて取るとコンボ倍率が上がります（5匹ごとに ×2, ×3 … 最大 ×5）
- **金ぼたる**（橙）：10点。提灯（ライフ）が減っていれば1つ回復
- **蜂**：網に入ると提灯が1つ消えます。3つ消えるとゲームオーバー
- ほたるを取り逃がすとコンボが途切れます
- 時間が経つほど、ほたるも蜂も速く・多くなります

### 操作

| 操作 | スマホ | PC |
| --- | --- | --- |
| 網を動かす | 画面を指でなぞる | マウス / ← → / A D |
| 一時停止 | II ボタン | P / Esc |

自己ベストはブラウザに保存されます。
